# 3D Rubik’s Cube Game 🧊
An Interactive 3D Puzzle Game for Android

This project is a fully interactive 3D Rubik’s Cube game built for Android. It demonstrates real-time 3D rendering, shader programming, and smooth gesture-based interactions using OpenGL ES, combined with a modern Android UI built using Jetpack Compose.

The application focuses on performance, graphics programming, and seamless integration between a 3D rendering engine and a declarative UI layer.

## ✨ Features

- Fully interactive 3D Rubik’s Cube with real-time rotations
- Gesture-based cube manipulation and face rotations
- Custom lighting and shading using GLSL
- Smooth animations and frame rendering
- Modern Android UI integrated with 3D rendering

---

## 🧱 Architecture

The game separates rendering logic from UI and input handling to maintain clarity and performance.

**Rendering Layer:**
- OpenGL ES 3.0 rendering pipeline
- Custom vertex and fragment shaders

**UI Layer:**
- Jetpack Compose for UI and user interactions
- Gesture detection and state coordination with the renderer

## 🎯 Motivation

This project was built to explore low-level graphics programming on Android, including OpenGL ES rendering, shader development, and performance optimization, while integrating a modern declarative UI using Jetpack Compose.

---

## 🧠 Key Learnings

- Building real-time 3D graphics using OpenGL ES
- Writing custom GLSL shaders for lighting and animations
- Managing gesture input for 3D transformations
- Integrating OpenGL rendering with Jetpack Compose UI
